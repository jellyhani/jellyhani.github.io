개인정보처리방침

대상 앱: Wonri YouTube Automation · 문서 기준: 2026년 10월 11일

원리의 단면 채널 운영자는 이 Windows 데스크톱 앱으로 자신의 YouTube 채널을 관리합니다. 이 방침은 앱의 Google 데이터 접근과 보관, 선택 자료의 AI 검토, 연결 중단 방법을 설명합니다.

1. 접근하는 데이터와 목적

  • 계정·채널 식별정보: 연결된 채널이 운영자의 지정 채널인지 확인합니다.
  • 영상과 제작 정보: 운영자가 승인한 영상 파일, 제목·설명·공개 설정과 처리 상태를 사용해 게시 및 예약을 관리합니다.
  • 채널·영상 성과: 조회, 시청, 반응, 구독 관련 공식 지표와 필요한 공개 댓글을 읽어 다음 영상의 기획·설명을 검토합니다.
  • 인증 정보: OAuth 토큰을 사용해 승인된 요청을 수행합니다. Google 계정 비밀번호를 앱에 입력받지 않습니다.

OAuth 권한은 https://www.googleapis.com/auth/youtube.upload, https://www.googleapis.com/auth/youtube.readonly, https://www.googleapis.com/auth/yt-analytics.readonly입니다.

2. 저장과 삭제

OAuth 토큰은 운영자의 Windows 자격 증명 관리자에, 채널 통계·제작 메타데이터·조회 캐시는 운영자의 로컬 작업 환경에 저장합니다. 이 소개 웹사이트가 토큰이나 비공개 채널 자료를 받거나 저장하지는 않습니다.

로컬 자료는 승인된 운영 목적에 필요한 동안 관리합니다. 운영자는 연결 중단과 로컬 토큰·캐시·통계 파일의 삭제를 요청하거나 직접 관리할 수 있습니다. 연결 철회만으로 이미 저장된 로컬 파일이나 YouTube에 게시된 영상이 자동 삭제되지는 않습니다. 게시 영상의 삭제는 YouTube에서 별도로 관리합니다.

3. AI 비서와 외부 서비스

운영자가 승인한 작업을 돕기 위해 선택된 자료·지표·필요한 댓글 내용을 운영자의 AI 비서인 Codex / OpenAI가 검토합니다. 목적은 사실 확인, 기획 및 게시 후 개선입니다. 전체 계정 자료를 공개하거나 판매하는 기능은 없습니다.

이 앱은 Google 사용자 데이터를 범용 AI 모델 훈련 목적으로 사용하지 않습니다. OpenAI 서비스의 보관 및 데이터 제어는 해당 서비스의 정책과 운영자 계정 설정에 따릅니다. 이 문서는 외부 AI 서비스의 모든 학습 설정이 꺼져 있거나 데이터가 전혀 보관되지 않는다고 보장하지 않습니다.

ElevenLabs는 독자적으로 작성한 내레이션을 음성으로 만드는 데 사용합니다. 이 용도로 Google OAuth 토큰을 전송하지 않습니다.

4. Google 데이터의 제한적 이용

Google API로 받은 데이터의 이용과 다른 서비스로의 전달은 Google API Services User Data Policy의 Limited Use 요구사항에 따라, 이 페이지에서 설명한 채널 운영 기능을 제공·개선하는 범위로 제한합니다. 광고 타기팅, 데이터 판매 또는 신용 평가 목적으로 사용하지 않습니다.

데이터 종류, 이용 목적 또는 전달 범위를 확대할 때에는 변경 내용을 알리고 필요한 동의를 먼저 받습니다. 이 방침은 Google의 앱 검증·인증 또는 보증을 받았다는 표시가 아닙니다.

5. 연결 철회와 지원

Google 계정의 연결된 앱 관리에서 해당 앱의 액세스 권한을 삭제할 수 있습니다. 철회 후에는 그 연결로 추가 API 작업을 수행할 수 없습니다. 절차는 Google 공식 도움말에서 확인할 수 있습니다.

운영자 본인은 앱을 관리하는 작업 환경에서 로컬 자료의 삭제나 이용 중단을 요청할 수 있습니다. 일반 안내와 지원 경로는 원리의 단면 공식 채널을 이용해 주세요. 공개 댓글에 인증 정보나 개인 자료를 남기지 마세요.

6. 이 웹사이트

이 정적 페이지에는 가입·로그인·업로드 양식, 외부 폰트, 분석 도구, 추적 스크립트 또는 별도로 설정하는 쿠키가 없습니다. 호스팅 서비스인 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 이는 앱 자체의 분석·추적 기능과 별개이며, GitHub Pages의 데이터 수집 안내를 따릅니다. 외부 링크를 방문하면 방문한 서비스의 방침이 적용됩니다.
